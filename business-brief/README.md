# business-brief

채용 공고를 붙여넣으면, 그 회사의 사업을 외부 자료로 추적해 **구직자를 위한 사업 브리프**를 만드는 Claude 스킬입니다.

최종 면접·오퍼 판단·합류 준비처럼 회사를 깊게 봐야 할 때 씁니다. 지원 전 가벼운 점검은 [role-match](../role-match/)가 맡습니다.

- 공고 해석: 자리 정체성, 숨은 요구, 이 자리가 풀 과제
- 핵심 포인트 매칭: 회사 상황 × 자리 정체성 → 포인트 3개 → 내 사례 → 번역 문장 · 결격 위험
- 외부 리서치: 재무·투자·트랙션·대표의 언어를 날짜·출처·유형 라벨이 달린 시계열로
- 사업·재무 구조: 매출원, 비용, 현금 약점 구간, 주장 vs 데이터 충돌
- 전략: 회사 언어로 비전 정렬, 고객 여정 플라이휠, 우선순위
- 실행: 30·60·90, 면접·첫 미팅 아젠다, 입사 전 체크리스트

## 설치
- **claude.ai**: [Releases](https://github.com/findot-ai/career-ai-skills/releases)에서 `business-brief.zip`을 받아 스킬로 업로드
- **Claude Code**: 이 폴더를 `~/.claude/skills/business-brief/`에 복사

## 사용
```
/brief
[채용 공고 붙여넣기 또는 URL]
[경력기술서 첨부 — 없으면 질문으로 받습니다]
관점: 면접 준비
```
